HTML allows us to add hyperlinks, images, audio, videos, and embedded content to make web pages interactive and attractive.

2. Image

Display an image using the <img> tag.

3. Audio

4. Video

Play a video using the <video> tag.

5. Google Maps (Iframe)

The <iframe> tag is used to embed another webpage, such as Google Maps, YouTube videos, or websites.
